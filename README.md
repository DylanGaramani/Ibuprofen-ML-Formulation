# Ibuprofen-ML-Formulation

Reproducible code and data supporting a retrospective machine-learning analysis of immediate-release ibuprofen formulations.

## Repository structure
- `code/` – analysis pipeline (ingest → cleaning → features → modeling → figures)
- `data/` – processed/shareable datasets (raw data may be restricted)
- `results/` – generated outputs (tables/figures)
- `docs/` – GitHub Pages site (methods + reproduction notes)

## Quick start (template)
1. Create environment (e.g., `conda env create -f environment.yml`)
2. Activate environment
3. Run pipeline (e.g., `python code/run_all.py`)
4. Outputs appear in `results/`
