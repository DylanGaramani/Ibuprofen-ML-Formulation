# Ibuprofen-ML-Formulation

Reproducible code and raw data supporting a retrospective machine-learning analysis of immediate-release ibuprofen formulations.

This repository accompanies the manuscript:

**Rational formulation design through retrospective machine learning methodology:  
Case study ibuprofen**

## Scope
- All **scripts** used for data ingestion, cleaning, feature engineering, modeling, and analysis are provided.
- All **raw input data** used in the study are openly available.

## Repository structure
- `code/` – analysis pipeline (ordered from ingestion to figure generation)
- `data/raw/` – raw formulation and metadata sources
- `docs/` – reproducibility notes and GitHub Pages site

## Reproducibility
Running the full pipeline regenerates all figures and tables reported in the manuscript.
