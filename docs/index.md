# Ibuprofen-ML-Formulation

Reproducible code and data supporting a retrospective machine-learning analysis of immediate-release ibuprofen formulations.

## What’s in this repository
- **code/**: scripts and notebooks (ingest → cleaning → modeling → figures)
- **data/**: processed data (raw data may be restricted and not shared)
- **results/**: generated tables and figures
- **docs/**: this GitHub Pages site
